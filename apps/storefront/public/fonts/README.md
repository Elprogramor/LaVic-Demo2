# Tipografia de marca

A identidade da LaVic especifica **All Round Gothic** para títulos, navegação e UI de destaque.
O arquivo da fonte não está incluído neste repositório por depender da licença do proprietário da marca.

Enquanto a fonte licenciada não for fornecida, o CSS usa `Manrope` como fallback moderno.
Quando a licença/arquivo estiver disponível, integrar por `next/font/local` ou pelo serviço oficial autorizado, sem distribuir o arquivo fora dos termos da licença.
