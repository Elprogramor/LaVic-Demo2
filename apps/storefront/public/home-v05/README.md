# LaVic Home v0.5 — mapa de imagens

Todos os caminhos abaixo são usados diretamente pela Home. Para trocar uma imagem manualmente durante a fase de design, substitua o arquivo mantendo o mesmo nome e formato, ou altere o caminho em `apps/storefront/content/home-v05.ts`.

## Hero
- `/public/home-v05/hero/hero-lime-scene.webp`
  - Uso: visual da metade direita do hero.
  - Recomendação: 1600×760 ou maior, composição horizontal, topo relativamente limpo.

- `/public/home-v05/flavors/green-grape.webp` *(demo)*
  - Recomendação: 800×1000, produto central, fundo simples, sem textos de interface.

## Importante
Os arquivos incluídos nesta versão são assets demonstrativos derivados da referência visual aprovada para permitir avaliar o layout imediatamente. Antes da publicação final, substitua-os por fotografia/arte oficial da LaVic e valide rótulos, claims e informações regulatórias.
