# LaVic Home v0.6 — imagens editáveis

Todas as imagens da Home v0.6 continuam em `public` para troca manual sem alterar componentes React.
Mantenha o mesmo nome e caminho para substituir uma arte diretamente.

## Hero
- `hero/hero-lime-minimal.webp` — cena principal do hero. Preferir composição limpa, sem textos, menus, botões ou UI incorporados à imagem. Proporção livre vertical/quadrada funciona porque o layout faz `contain`; recomendado mínimo 900 px de altura.

### Regra de produção
As imagens não devem conter header, botões, preços, claims ou textos essenciais. Esses elementos permanecem como HTML real para acessibilidade, responsividade e edição futura pelo Admin.
