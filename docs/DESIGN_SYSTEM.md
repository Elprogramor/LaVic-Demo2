# Design System — LaVic v0.2

## Direção
**Natural premium contemporânea com linguagem de marca moderna.** A storefront deve parecer um site de marca com e-commerce embutido, e não uma landing page ou catálogo genérico.

## Tipografia
- Identidade, títulos, navegação, botões e destaques: **All Round Gothic**.
- Corpo e fallback técnico: **Manrope**.
- All Round Gothic não é distribuída no repositório; integrar somente quando a marca fornecer uma fonte/licença válida.
- Não usar serif editorial na v0.2.

## Paleta
- Canvas: `#FBFBF8`
- Institucional: teal profundo `#005561` / `#003F47`
- Acento energético: laranja `#D96D2A`
- Limão: família verde
- Morango: família coral/vermelha
- Sabores podem mudar a atmosfera sem substituir a identidade institucional.

## Forma
- Cantos arredondados fazem parte da linguagem v0.2.
- Cards editoriais principais: 38–56px.
- Botões: pill.
- Evitar transformar todos os elementos em caixas arredondadas; usar principalmente em blocos de campanha, mídia e comércio.

## Composição
- Hero assimétrico com headline empilhada `Viva / Com / Gás.`.
- Produto deve atravessar o grid e dominar a composição.
- Menos grids repetitivos; variar escala e proporção entre seções.
- Fotografia e whitespace são parte da hierarquia.
- Home vende marca primeiro; catálogo/checkout vendem produto de forma mais funcional.

## Ícones
Flaticon UIcons Thin Rounded (`fi-tr`) exclusivamente para ícones funcionais.

## Assets
Imagens em `public/demo` são placeholders. A versão comercial deve migrar para fotografia real da LaVic com direção de arte consistente.
